# Flow Unlock

Chrome MV3-расширение, которое снимает клиентскую проверку региона на `flow.google.com`.

## Установка

1. Открой `chrome://extensions` (или `edge://extensions`).
2. Включи **Developer mode**.
3. **Load unpacked** → выбери эту папку.
4. Закрепи расширение на панели.

## Использование

1. Открой <https://flow.google.com/>.
2. Смотри на бейдж:
   - `ON` — расширение включено и ждёт нужный бандл;
   - `OK` — патч применён;
   - `ERR` — ошибка, текст в попапе.
3. Если вкладка Flow уже была открыта, открой попап и нажми **Перезапустить**.
4. Закрой DevTools (F12) на вкладке Flow: Chrome разрешает только один debugger на вкладку.

## Как это работает

Расширение подключается к вкладке через `chrome.debugger`, включает `Fetch` для скриптов с `www.gstatic.com`, находит основной бандл `AiSandboxAngularFrontend` и заменяет вызов регионального флага `_.X(a,31)` на `true`. Возрастной флаг `_.X(a,32)` остаётся нетронутым. Посторонние чанки пропускаются без изменений. Ответ отдаётся из памяти с отключённым кэшем.

Никакой телеметрии и внешних запросов: код работает только с `flow.google.com` и `www.gstatic.com`.

## Ограничения

- Google может изменить бандл. Тогда поиск сигнатуры не сработает и появится `ERR` «сигнатура не найдена» — расширение нужно обновить.
- Только desktop Chrome/Edge: нужен `chrome.debugger`.
- Предупреждение Chrome «Debugging tabs» — ожидаемо, разрешение нужно для перехвата.
- Снимается только клиентский региональный гейт. Серверные проверки, доступность аккаунта и лимиты usage не затрагиваются.
- Не связано с Google. Может нарушать ToS. Без гарантий.

## Файлы

| Файл | Назначение |
| --- | --- |
| `manifest.json` | MV3-манифест |
| `background.js` | CDP-сессия, перехват бандла, редиректы |
| `patch.js` | Поиск и замена сигнатуры в бандле |
| `content.js` | Пинг вкладки и повторный патч при `/unsupported-country` |
| `popup.html/css/js` | Статус, включение, кнопки |
| `icons/*.png` | Иконки 16/48/128 |

## Приватность

Расширение не собирает и не отправляет данные. Настройки хранятся в `chrome.storage.local`.
